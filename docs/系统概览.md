# auth-center 系统概览

> 一页看懂：这个系统是什么、提供哪些服务、有哪些表、怎么跑起来。
> 深入阅读：[统一认证中心设计文档](统一认证中心设计文档.md) ｜ [业务系统接入指南](业务系统接入指南.md) ｜ [开发进度](开发进度.md)

## 1. 系统是什么

**集团统一认证中心（IdP/IAM）**：管理全集团主账号生命周期（人）、应用注册与进门权（门）、
系统管理员标签（店长标签），为 ERP/MES 等业务系统提供 **OIDC 单点登录**与**服务间用户同步 API**。

```
                     ┌────────────── 认证中心 auth-center ──────────────┐
   浏览器 ──SSO跳转──▶│ 统一登录页/授权页(5174)  管理端(5174)            │
   ERP/MES ◀─REST───▶│ OIDC 端点(8082/api)     服务间 API(/service/**) │
                     │ MySQL auth_db(13306)    Redis(16379)            │
                     └─────────────────────────────────────────────────┘
   业务系统只通过 HTTP 对接；中心不主动调业务系统（拉模式对账）。
```

## 3. 对外端点一览

### OIDC 协议端点（issuer = `http://localhost:8082/api`）

| 端点 | 方法 | 用途 |
|------|------|------|
| `/.well-known/openid-configuration` | GET | 发现文档 |
| `/.well-known/jwks.json` | GET | RS256 验签公钥（JWKS） |
| `/oauth/authorize` | POST | 授权确认（统一登录页登录后调用，返回带 code/state 的回调地址；consent 可配） |
| `/oauth/token` | POST | 授权码+PKCE 换 access/id token；`client_credentials` 换服务令牌 |
| `/oauth/userinfo` | GET | 用户信息（RS256 access token） |
| `/oauth/logout` | POST | 单点登出（令牌 jti 拉黑） |

前端授权页（业务系统重定向入口）：`http://localhost:5174/oauth/authorize?client_id=...&redirect_uri=...&response_type=code&scope=openid&state=...&code_challenge=...&code_challenge_method=S256`

### 服务间 API（业务系统后端调用，client_credentials 服务令牌认证）

| 端点 | 方法 | 用途 |
|------|------|------|
| `/service/apps/{clientId}/users?updatedSince=` | GET | 用户增量/全量同步（`active=false`+inactiveReason=LEFT/SUSPENDED/APP_DISABLED，SCIM 风格对账） |
| `/service/apps/{clientId}/users/{工号}/status` | PUT | 应用级启停（body `{"enabled":false}`，仅在职员工可操作） |

### 管理端接口（管理端 JWT 认证，@PreAuthorize 角色控制）

| 前缀 | 用途 | 角色 |
|------|------|------|
| `/auth/**` | 登录/登出/探活 | 白名单（login） |
| `/idm/orgs/**`、`/idm/users/**` | 组织树、主账号生命周期 | SUPER_ADMIN |
| `/apps/**`、`/apps/{clientId}/assignments/**` | 应用注册、角色标签、分配/启停 | SUPER_ADMIN |
| `/audit/login-logs`、`/audit/op-logs` | 审计查询 | SUPER_ADMIN / AUDITOR |

## 4. 数据表一览（库 `auth_db`，版本段：system V1x / idm V10x / app V20x / token+audit V30x）

| 表 | 版本 | 用途 | 关键列 |
|----|------|------|--------|
| `sys_role` | V1 | 平台角色（SUPER_ADMIN/APP_ADMIN/AUDITOR） | code、name |
| `sys_user_role` | V1 | 用户×平台角色 | user_id、role_id |
| `idm_org` | V10 | 组织树 | code、name、parent_id、sort、status(1启用/0停用) |
| `idm_user` | V10 | **主账号**（生命周期收口） | employee_no(不可变唯一键)、username、real_name、org_id、position、email、phone、password(BCrypt)、status(1在职/2离职终态/3全局停用)、entry_date、leave_date |
| `idm_user_event` | V10 | 生命周期事件流水（追加型） | user_id、event_type(CREATE/TRANSFER/LEAVE/STATUS_CHANGE/RESET_PWD)、detail(JSON) |
| `app_client` | V20 | 应用注册（OAuth2 client） | client_id(唯一)、client_secret(BCrypt)、app_name、redirect_uri、access_token_validity、consent_required、status、admin_user_id(委托预留) |
| `app_client_role` | V20 | 应用声明的角色标签 | client_id、role_code(如 erp.admin)、role_name |
| `app_user_assign` | V20 | 用户×应用进门权 + **应用级状态** | client_id、user_id、status(1启用/0应用级禁用) |
| `app_user_role` | V21 | 用户×应用×角色标签 | client_id、user_id、role_code |
| `token_key` | V30 | OIDC RS256 签名密钥（自动生成） | kid、algorithm、public_key/private_key(PEM)、status(轮换预留) |
| `audit_login_log` | V30 | 登录日志（追加型） | user_id、username、login_type(ADMIN/OIDC)、client_id、success、fail_reason、ip、user_agent |
| `audit_op_log` | V30 | 管理端操作日志（追加型，写操作切面） | user_id、username、method、uri、status_code、detail(脱敏)、ip、cost_ms |

> 所有业务表另含标准列：id、tenant_id(默认1000，预留租户)、create_by/create_time/update_by/update_time/deleted。
> 唯一索引均含 tenant_id；共享表（app_client/app_client_role/token_key/sys_role 等）见 `TenantConfig.TENANT_SHARED_TABLES`。

## 5. Redis 键一览

| 键模式 | 用途 | TTL |
|--------|------|-----|
| `token:{userId}:{jwt}` | 管理端在线会话（键删即失效；离职/停用全删） | 令牌有效期 |
| `auth:blacklist:{jwt}` | 管理端登出黑名单 | 剩余有效期 |
| `oidc:code:{code}` | 一次性授权码（绑定 PKCE challenge） | 60 秒 |
| `oidc:blacklist:{jti}` | OIDC 令牌登出黑名单 | 剩余有效期 |

## 6. 工程结构

```
auth-backend/（Java 21 + Spring Boot 3.3，包名 com.auth）
├── auth-base/            common(Result/异常/i18n) + framework(安全/租户/审计填充/分页/切面)
├── auth-platform/        system(管理端RBAC/JWT/审计) + idm(组织/主账号/生命周期状态机)
├── auth-biz/             app(应用注册/分配/服务间API) + oidc(协议端点/RS256令牌/密钥)
└── auth-bootstrap/       启动模块 AuthApplication（8082, context /api）
auth-web/                 React18+TS+AntD5 管理端 + 统一登录/授权页（5174）
script/sql/migration/     Flyway 迁移脚本（历史不可改）
script/demo/              demo-client-flow.sh（OIDC全流程演示）、seed-demo-data.sh（演示数据）
```

## 7. 快速启动与验证

```bash
docker compose up -d                                          # MySQL 13306 / Redis 16379
mvn -f auth-backend/pom.xml install -DskipTests               # JDK21
java -jar auth-backend/auth-bootstrap/target/*.jar            # 仓库根执行（Flyway 自动建表）
cd auth-web && pnpm install && pnpm dev                       # 前端 5174
./script/demo/seed-demo-data.sh                               # 演示数据（可选，幂等）
./script/demo/demo-client-flow.sh                             # OIDC 全流程演示
```
