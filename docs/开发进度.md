## 已定稿的实现决策（勿推翻）

1. **租户策略 = 预留租户维度**：BaseEntity 含 tenant_id（默认 1000）；TenantContextHolder；
   JWT 带 tenantId；共享表白名单见 `TenantConfig.TENANT_SHARED_TABLES`。
2. **两套令牌体系**：管理端 HS256（JwtTokenProvider，Redis 在线键+黑名单）；
   OIDC RS256（OidcTokenService，token_key 表自动生成密钥，JWKS 发布）。勿混用。
3. **模块依赖**：common ← framework ← system ← idm ← {app, oidc} ← bootstrap。
4. 主账号表 = `idm_user`；工号不可变；登录名默认同工号。
5. **SPA 版授权码流**：业务系统重定向到前端 `/oauth/authorize`（带 OIDC 参数）→
   登录/consent 后前端 POST `/api/oauth/authorize`（带管理端 JWT）→ 拿 redirectUri 跳回。
   对业务系统而言与标准 RFC 6749 重定向流一致。
6. **服务间 API 认证**：client_credentials → RS256 service token（token_use=service，aud=client_id）→
   ServiceTokenFilter（/service/**，白名单+自管认证）→ ROLE_SERVICE + principal=client_id。
