# 业务系统接入指南（ERP / MES / 后续系统）

> 目标读者：业务系统后端开发。读完即可完成 SSO 接入与服务间 API 对接。

## 0. 前置信息

| 项 | 值 |
|----|----|
| 认证中心后端 | `http://localhost:8082/api`（issuer，可配置） |
| 统一登录页 | `http://localhost:5174/oauth/authorize?...`（前端，参数透传） |
| JWKS（验签公钥） | `GET {issuer}/.well-known/jwks.json`（RS256，按 kid 匹配） |
| 发现文档 | `GET {issuer}/.well-known/openid-configuration` |
| 演示凭证 | 应用 `demo-client` / 密钥 `demo-secret`（仅演示） |

## 1. 应用注册（中心侧操作）

由认证中心超管在管理端"应用管理"注册，获得：

- `client_id`（如 `erp-web`）
- `client_secret`（**明文仅注册/重置时展示一次**）
- `redirect_uri`（授权码投递点，须精确匹配，如 `http://localhost:8080/sso/callback`）
- 角色标签声明（本期即 `erp.admin` 系统管理员标签）

然后：把需要登录本系统的用户**分配**给该应用（进门权），按需授予 `xxx.admin` 标签。

## 2. OIDC 授权码 + PKCE 登录流

### 2.1 发起登录（浏览器重定向到统一登录页）

```
{authorizePage}?client_id=erp-web
  &redirect_uri=http://localhost:8080/sso/callback
  &response_type=code
  &scope=openid profile
  &state={随机串}
  &code_challenge={BASE64URL(SHA256(verifier))}
  &code_challenge_method=S256
```

`{authorizePage}` 为中心前端授权页（默认 `http://localhost:5174/oauth/authorize`）。
verifier 为 43~128 位随机串，存于本系统会话，回调后用于换令牌。

用户在统一登录页完成登录（首次需授权确认，视应用配置）后，浏览器被重定向回：

```
{redirect_uri}?code={授权码}&state={原样回传}
```

> MES 侧已在 ../sf-mes 预留 `/sso/callback` 与本地直登降级，对接面即本节。

### 2.2 换取令牌（业务系统后端）

```
POST {issuer}/oauth/token
Content-Type: application/x-www-form-urlencoded
Authorization: Basic base64(client_id:client_secret)

grant_type=authorization_code
&code={授权码}
&redirect_uri={与授权请求一致}
&code_verifier={verifier}
```

响应：

```json
{
  "access_token": "eyJ...",        // RS256 JWT，aud=client_id
  "id_token": "eyJ...",            // scope 含 openid 时签发
  "token_type": "Bearer",
  "expires_in": 7200,
  "scope": "openid profile"
}
```

### 2.3 access token claims

| claim | 说明 |
|-------|------|
| `sub` | 中心用户 ID |
| `employee_no` | 工号（**业务系统匹配本地用户的唯一键，不可变**） |
| `username` / `name` | 登录名 / 姓名 |
| `org_id` / `tenant_id` | 组织 / 租户（ABAC 预留） |
| `roles` | 该用户在本应用的角色标签（如 `["erp.admin"]`） |
| `token_use` | 固定 `access` |

`xxx.admin` 标签即"系统管理员"判定依据；普通角色由本系统管理员在系统内部自授。

### 2.4 验签

用 JWKS 公钥验 RS256 签名（按 header.kid 选 key），校验 `iss` / `aud` / `exp`。
业务系统侧首次接入可拉取 userinfo 校验令牌：

```
GET {issuer}/oauth/userinfo
Authorization: Bearer {access_token}
```

### 2.5 登出

```
POST {issuer}/oauth/logout
Authorization: Bearer {access_token}
```

中心将令牌 jti 拉黑（TTL=剩余有效期）；员工在中心侧离职/全局停用时全部令牌即时失效。

## 3. 服务间 API（管理端同步 / 应用级启停）

### 3.1 获取 service token

```
POST {issuer}/oauth/token
Authorization: Basic base64(client_id:client_secret)

grant_type=client_credentials
```

### 3.2 用户同步（对账式，SCIM 风格）

```
GET {issuer}/service/apps/erp-web/users?updatedSince=2026-09-06T00:00:00
Authorization: Bearer {service_token}
```

返回本应用已分配用户；`active=false` 时业务系统应将本地用户软删除（active=false），
`inactiveReason`：`LEFT`（离职）/`SUSPENDED`（全局停用）/`APP_DISABLED`（应用级禁用）。
定时全量对账 + `updatedSince` 增量皆可。

### 3.3 应用级启停（本系统管理端"禁用/启用某员工"）

```
PUT {issuer}/service/apps/erp-web/users/{employeeNo}/status
Authorization: Bearer {service_token}
Content-Type: application/json

{"enabled": false}
```

仅影响本应用；对离职/全局停用工号返回业务异常（在中心侧处置）。
